[1/33] Pengantar Tur Celang

Selamat datang di Tur Celang (A Tour of Celang)! Modul ini dirancang agar Anda dapat mempelajari konsep, sintaks, dan keistimewaan bahasa pemrograman Celang langkah demi langkah secara interaktif.

Setiap langkah terdiri dari dua bagian utama:

  • Panel Kiri: Penjelasan konsep ringkas, panduan teori, serta tantangan praktik.
  • Panel Kanan: Editor interaktif untuk langsung mengubah dan mengeksekusi kode Celang di peramban web tanpa perlu memasang aplikasi apa pun.

Seluruh komputasi dijalankan secara aman dan privat di perangkat Anda ditenagai oleh mesin Celang WebAssembly.

🎯 Tantangan Praktik:
Tekan tombol ▶ Jalankan Kode atau tekan pintasan Ctrl + Enter (Cmd + Enter di macOS) untuk menjalankan program perdana Anda!
